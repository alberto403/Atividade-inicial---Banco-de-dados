# Atividade inicial - Banco de dados

Repositório com os arquivos produzidos para a atividade de modelagem e banco de dados.

## Conteúdo

- `modelo_bd_nota_fiscal.sql` - modelo de banco para nota fiscal eletrônica
- `modelo_notafiscal.sql` - versão detalhada do esquema da NFC-e com exemplos de inserção
- `modelo_bd_vacina.sql` - modelo para registro de vacinação e histórico de doses
- `vacina-app-ios/` - aplicação iOS/Capacitor relacionada ao tema de vacinação
- `vacina-app-ios-2/` - segunda versão da aplicação

## Objetivo

A atividade teve como foco a criação de modelos de dados, estrutura relacional e organização de informações para diferentes contextos: saúde e nota fiscal.

## Observação

Os arquivos foram enviados para este repositório para manter o histórico e facilitar a entrega da atividade.
